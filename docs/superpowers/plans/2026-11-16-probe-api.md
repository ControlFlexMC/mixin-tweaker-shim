# 对外可依赖的 Mixin 查询 API 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `mixin-tweaker-shim` 变成一个别人可以在 `@Mod(dependencies=...)` 里依赖的 mod，并提供"有没有 Mixin / 什么版本 / 够不够"三个查询。

**Architecture:** 三个任务。先把版本比较做成纯函数（不碰构建、不碰 FML），再给这个 jar 加上 mod 身份（容器 + `mcmod.info` + `ForceLoadAsMod`）并放宽 un-ignore 条件，最后在真机上验证四格。前两个任务各自可测、可提交；第三个只产证据。

**Tech Stack:** Java 8 字节码（`options.release = 8`）、Gradle 8.1.1、JUnit 5、Forge 1.12.2-14.23.5.2859（仅注解）。

**Spec:** `docs/superpowers/specs/2026-11-16-probe-api-design.md`

## Global Constraints

- 产物必须是 Java 8 字节码（`options.release = 8`），构建 JVM 用 11..19 的 JDK（本机 17）。
- jar 内 class 数量由 `verifyShimJar` 逐一点名校验；任何任务结束时数量与名单必须一致。
- tweak 阶段的两个类（`MixinTweaker`、`MixinTweakShim`）**不得引用任何 Minecraft / Forge 类型**；只有容器类可以。
- 任何失败路径**不得抛出**；查询 API 返回 `UNKNOWN`/`null` 而不是异常。
- `ForceLoadAsMod` 恒表示"这是 mod"；只写 `TweakClass` 恒表示"这是库"。
- modid 固定 `mixintweakershim`；jar 名固定 `mixin-tweaker-shim-0.9.0.jar`。
- 版本号单一来源是 `build.gradle` 的 `version`；`mcmod.info` 用模板展开。

## Review Focus

1. **门槛串非法**（`null`、`""`、`"dev"`）——调用方传进来的可能是配置里的空值；期望是 `UNKNOWN`，不是异常。
2. **版本串带后缀**（`"0.8.2-SNAPSHOT"`、`"0.8"`、`"0.7"`）——真实 `VERSION` 出现过这些形态；期望与同主版本号比较相等，而不是 `UNKNOWN`。
3. **`START_FAILED` 时 jar 不在 mod 列表**——provider 在但 `doInit` 抛异常时，调用方的 `required-after` 会先报缺失依赖；期望即使在这种情况下 shim 也被放回列表。
4. **段落数不同**（`"0.8"` vs `"0.8.0"`）——期望相等，不能因为少一段判 `BELOW`。
5. **容器被装到别的 MC 版本**——期望 FML 明确拒绝（`acceptedMinecraftVersions`），而不是静默半工作。

```java
@Test
@DisplayName("checkVersion compares numerically, not lexicographically")
void checkVersionComparesNumerically() {
    MixinTweakShim.bindBootstrap(StubMixinBootstrap.class.getName());   // VERSION = "0.8.7"

    assertEquals(MixinTweakShim.VersionCheck.AT_LEAST, MixinTweakShim.checkVersion("0.7.10"),
            "0.8.7 is above 0.7.10; a string comparison would say the opposite");
    assertEquals(MixinTweakShim.VersionCheck.BELOW, MixinTweakShim.checkVersion("0.8.8"));
    assertEquals(MixinTweakShim.VersionCheck.AT_LEAST, MixinTweakShim.checkVersion("0.8.7"));
}

@Test
@DisplayName("missing segments count as zero, so 0.8 equals 0.8.0")
void checkVersionPadsMissingSegments() {
    MixinTweakShim.bindBootstrap(EightOnlyStubMixinBootstrap.class.getName());   // VERSION = "0.8"

    assertEquals(MixinTweakShim.VersionCheck.AT_LEAST, MixinTweakShim.checkVersion("0.8.0"));
    assertEquals(MixinTweakShim.VersionCheck.BELOW, MixinTweakShim.checkVersion("0.8.0.1"));
}

@Test
@DisplayName("a suffix after the digits does not make the version incomparable")
void checkVersionToleratesSuffixes() {
    MixinTweakShim.bindBootstrap(SnapshotStubMixinBootstrap.class.getName());    // VERSION = "0.8.2-SNAPSHOT"

    assertEquals(MixinTweakShim.VersionCheck.AT_LEAST, MixinTweakShim.checkVersion("0.8.2"));
    assertEquals(MixinTweakShim.VersionCheck.BELOW, MixinTweakShim.checkVersion("0.8.3"));
}

@Test
@DisplayName("unknown versions and invalid floors are UNKNOWN, never exceptions")
void checkVersionReturnsUnknownInsteadOfThrowing() {
    MixinTweakShim.bindBootstrap("org.spongepowered.asm.launch.DoesNotExist");
    assertEquals(MixinTweakShim.VersionCheck.UNKNOWN, MixinTweakShim.checkVersion("0.7.10"),
            "no bootstrap means no version to compare");

    MixinTweakShim.resetForTest();
    MixinTweakShim.bindBootstrap(UnknownVersionStubMixinBootstrap.class.getName());  // VERSION = "unknown"
    assertEquals(MixinTweakShim.VersionCheck.UNKNOWN, MixinTweakShim.checkVersion("0.7.10"));

    MixinTweakShim.resetForTest();
    MixinTweakShim.bindBootstrap(StubMixinBootstrap.class.getName());
    assertEquals(MixinTweakShim.VersionCheck.UNKNOWN, MixinTweakShim.checkVersion(null));
    assertEquals(MixinTweakShim.VersionCheck.UNKNOWN, MixinTweakShim.checkVersion(""));
    assertEquals(MixinTweakShim.VersionCheck.UNKNOWN, MixinTweakShim.checkVersion("dev"));
}
```

`EightOnlyStubMixinBootstrap`（`"0.8"`）、`SnapshotStubMixinBootstrap`（`"0.8.2-SNAPSHOT"`）、`UnknownVersionStubMixinBootstrap`（`"unknown"`），均含 `start()` 返回 true、`doInit(List)`、`inject()`、`getPlatform()`、`VERSION` 字段。

- [ ] **Step 3: 实现**

在 `MixinTweakShim` 内加嵌套枚举与 `checkVersion`，签名如上。解析规则：

- 两侧都解析成 `int[]`，**每段取前导数字**（`"0.8.2-SNAPSHOT"` → `[0,8,2]`）；某段无前导数字即为不可比；

- Produces: `@Mod(modid = "mixintweakershim", ...)` 的容器 `com.ifels.mixinshim.MixinShimMod`；jar manifest 增加 `ForceLoadAsMod: true`。

- [ ] **Step 4: 写容器与元数据**

`MixinShimMod.java`：

```java
@Mod(modid = "mixintweakershim", name = "Mixin Tweaker Shim",
     acceptableRemoteVersions = "*", acceptedMinecraftVersions = "[1.12.2]")

}
```

不写 `version`：版本由 `mcmod.info` 提供，保持单一来源。

`src/main/resources/mcmod.info`（模板，`${version}` 由 `processResources` 展开）：

```json
[{
  "modid": "mixintweakershim",
  "name": "Mixin Tweaker Shim",
  "description": "Supplies the Mixin tweaker class name on instances with no provider, and answers which Mixin a launch actually got.",
  "version": "${version}",
  "mcversion": "1.12.2",
  "authorList": ["ControlFlexMC"]
}]
```

`build.gradle` 的 `processResources` 里 `expand('version': project.version)`。

- [ ] **Step 5: 让 jar 自己要求被当 mod 加载**

`jar { manifest { attributes('TweakClass': ..., 'ForceLoadAsMod': 'true') } }`。

同时把 `injectIntoClassLoader` 的 un-ignore 条件从 `currentState() == TweakState.ABSENT` 改为 `!delegated`（覆盖 `ABSENT` 与 `START_FAILED`）——否则 `START_FAILED` 时 jar 留在 ignored 表，调用方的 `required-after` 会先报缺失依赖。

- [ ] **Step 6: 门禁名单改 5 个并跑通**

名单加上 `com/ifels/mixinshim/MixinShimMod.class`；同时保留"`org/` 下只允许 `MixinTweaker.class`"的断言。
